## Sobre mí

Soy desarrollador backend enfocado en **Java y Spring Boot**. He participado en productos colaborativos y aplicaciones full stack, principalmente en el diseño e implementación de APIs, autenticación, persistencia, integraciones y preparación de entornos de despliegue.

Mi experiencia práctica incluye:

- Desarrollo de APIs REST con Java y Spring Boot.
- Autenticación y autorización con Spring Security y JWT.
- Persistencia con Spring Data JPA, PostgreSQL, MySQL y migraciones con Flyway.
- Organización modular de aplicaciones con Spring Modulith.
- Documentación de contratos con OpenAPI y Swagger.
- Integraciones con Cloudinary, Resend y servicios desarrollados en Python/FastAPI.
- Configuración de Docker, variables de entorno y despliegues en servicios administrados.
- Integración backend–frontend en equipos multidisciplinarios.

Actualmente continúo fortaleciendo arquitectura de software, testing, rendimiento y desarrollo frontend con React y TypeScript como complemento a mi perfil backend.

## Proyectos destacados

### EleVideo · Procesamiento inteligente de video

Plataforma que transforma videos horizontales en contenido vertical 9:16 para TikTok, Instagram Reels y YouTube Shorts. Combina una aplicación web, un backend modular y un servicio de procesamiento de video.

**Contribución principal:**

- Evolución del backend Spring Boot hacia una arquitectura de monolito modular.
- Autenticación con JWT y organización de dominios como usuarios, proyectos, videos, jobs y notificaciones.
- Integración con Cloudinary para almacenamiento y entrega de contenido.
- Comunicación con un servicio Python/FastAPI mediante solicitudes y webhooks.
- Seguimiento de trabajos de procesamiento y notificaciones al completar o fallar.

**Stack:** Java 17, Spring Boot, Spring Modulith, PostgreSQL, React, Python, FastAPI, MediaPipe, OpenCV, FFmpeg y Cloudinary.

[Demo](https://elevideo.cambers.lat) · [API](https://elevideo-ec.onrender.com/swagger-ui/index.html) · [Repositorio](https://github.com/EdgarCamberos1894/elevideo)
